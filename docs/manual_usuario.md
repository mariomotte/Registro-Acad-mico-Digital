# Manual de Usuario - EduControl.A.G.G

Este manual describe el uso de la plataforma para administradores, directivos, docentes y auxiliares.

---

## 1. Acceso al Sistema

1. Ingrese a la direccion del sistema.
2. Inicie sesion con su correo y contrasena.
3. El sistema cargara el panel correspondiente a su rol.

Roles disponibles:

* Administrador
* Director
* Subdirector
* Docente
* Auxiliar

---

## 2. Gestion de Alumnos

Ubicacion: **Alumnos**

* Busque estudiantes por DNI, nombres o apellidos.
* Registre alumnos nuevos si su rol tiene permiso.
* Edite datos personales, grado, seccion, estado y datos del apoderado.
* Abra la ficha del alumno para revisar su historial de incidencias, tardanzas e inasistencias registradas como reportes.

---

## 3. Registro de Incidencias

Ubicacion: **Incidencias > Nuevo Reporte**

1. Seleccione el alumno.
2. Seleccione el tipo de incidencia.
3. Indique severidad, fecha y hora del suceso.
4. Escriba la descripcion.
5. Adjunte evidencias si corresponde.
6. Use el refinador con IA si desea formalizar el texto.
7. Guarde el reporte.

Tipos habituales:

* Inasistencia
* Tardanza
* Problema de comportamiento
* Problema de salud
* Conflicto entre alumnos
* Observacion academica

---

## 4. Alertas

Ubicacion: **Alertas**

El sistema genera alertas cuando:

* se registra una incidencia de severidad alta;
* un alumno acumula reincidencias.

El rol Auxiliar recibe notificaciones en tiempo real y puede marcar alertas como visualizadas.

---

## 5. Dashboard

Ubicacion: **Panel de Control**

El dashboard cambia segun el rol:

* Directivos ven metricas institucionales, graficos y casos prioritarios.
* Docentes ven sus reportes y alumnos asignados por tutoria.
* Auxiliares ven alertas activas, incidencias del dia y casos de atencion prioritaria.

---

## 6. Reportes

Ubicacion: **Reportes**

* Filtre por alumno, grado, seccion, tipo, severidad y fechas.
* Revise KPIs de incidencias, tardanzas e inasistencias.
* Exporte informacion en CSV.
* Use la vista de impresion para respaldo fisico o PDF.
